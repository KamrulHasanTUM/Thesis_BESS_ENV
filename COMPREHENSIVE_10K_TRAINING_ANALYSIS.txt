2. "Don't worsen much" → Avoid penalty

This creates UNSTABLE LEARNING around 6k steps as PPO tries to balance these conflicting signals.

New addition: soc_drift_penalty = -10 × |mean(SoC) - 0.5|

Q1: Why did rollout mean reward go down consistently after 6k?

A: Premature convergence to local minimum caused by:

1. REWARD IMBALANCE: bonus_constant (30) still too low vs activity bonuses (25). Agent confused about priorities.

2. SOC DRIFT PENALTY CONFLICT: Agent learns "discharge helps congestion" but "discharge causes SoC drift which is penalized". At 6k, exploitation phase begins and agent tries to balance these conflicting objectives, leading to conservative, suboptimal policy.

3. ENTROPY REDUCTION: At 6k steps (~3 PPO updates), entropy effect decreases, agent commits to learned strategy. But strategy is suboptimal, and agent can't escape.

4. VALUE FUNCTION CONVERGENCE: PPO's value function stabilizes around 6k, making it harder to explore new strategies. Agent stuck in local minimum.

5. INSUFFICIENT EXPLORATION: Only 6k steps isn't enough to explore the full state-action space. Agent converged before finding optimal policy.

SOLUTION: Need to:
- Further increase bonus_constant (30 → 50)
- Redesign soc_drift_penalty to allow temporary drift
- Increase training length (10k → 50k+)
- Possibly reduce learning rate for more stable convergence
