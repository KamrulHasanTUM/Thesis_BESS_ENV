   - Congestion reward: bonus_constant * (loading_before - loading_after)
   - SoC penalty: soc_penalty_weight * num_near_bounds
   - Flexibility bonus: flexibility_bonus_weight * distance_metric
   - Clipping penalty: soc_clipping_penalty * num_clipped

   The problem:
   - Penalties are CERTAIN (always applied for violations)
   - Congestion reward is UNCERTAIN (depends on grid state)
   - Agent learns to minimize certain penalties → Do nothing!

   - soc_clipping_penalty: -10

   There's NO reward for:
   - Taking action (any action)
   - Exploring the action space

   - Using the BESS capacity

   Once agent discovers "do nothing" is safe, it never explores again.

3. **ENTROPY COEFFICIENT TOO LOW**

   From config: ent_coef: 0.01

   This value is very low, meaning:
   - Agent stops exploring quickly
   - Policy becomes deterministic fast

   - No incentive to try other actions

4. **NO PENALTY FOR INACTION**

   There's no mechanism to:
   - Penalize zero actions

DETAILED REWARD STRUCTURE ANALYSIS

Let's calculate what the agent "sees" for different actions:

SCENARIO 1: Agent Takes Action (e.g., discharge 20 MW)

Potential outcomes:

Risk/Reward ratio: High variance, uncertain outcome

SCENARIO 2: Agent Does Nothing (action = [0, 0, 0, 0, 0])
-----------------------------------------------------------
Guaranteed outcomes:
- Congestion reward: 0 (no action, loading unchanged)
- SoC penalty: 0 (stays at 0.5, far from bounds)
- Flexibility bonus: +10 (exactly at center)
- Clipping penalty: 0 (no action to clip)

Expected reward: 0 + 0 + 10 + 0 = +10 (GUARANTEED)
Worst case: Same (no variance)

Risk/Reward ratio: Zero risk, small but certain positive reward

**Agent's Logic: "Why take risky actions (variance -225 to +160) when I can
safely get +10 every step by doing nothing?"**

This is RATIONAL from agent's perspective, but WRONG for our objective!

================================================================================
MATHEMATICAL PROOF OF REWARD HACKING
================================================================================

Define:
- R_action = Expected reward when taking action
- R_nothing = Expected reward when doing nothing
- σ_action = Standard deviation of R_action
- σ_nothing = Standard deviation of R_nothing = 0

From training data:

R_action = E[bonus_constant * Δloading + penalties]
         ≈ 100 * E[Δloading] + (-35) * P(violation) + (-10) * P(clipping) + 10

E[Δloading] with random actions ≈ 0 (no systematic improvement without learning)
P(violation) ≈ 0.30 (30% chance of hitting bounds with aggressive action)
P(clipping) ≈ 0.40 (40% of actions get clipped)

R_action ≈ 100 * 0 + (-35) * 0.3 + (-10) * 0.4 + 10
        ≈ 0 - 10.5 - 4 + 10
        ≈ -4.5

R_nothing = 0 + 0 + 10 + 0 = +10

**Therefore: R_nothing > R_action**

The agent correctly learned that doing nothing (+10) is better than
taking actions (-4.5) given the current reward structure!

This is not a bug in the learning algorithm. This is a bug in our
reward design. The agent is behaving optimally for a poorly specified
objective function.

================================================================================
CRITICAL DESIGN FLAWS IDENTIFIED
================================================================================

1. **MISSING: Baseline Comparison**

   Current: reward = f(state_after_action)
   Better: reward = f(state_after_action) - f(state_without_action)

   This penalizes "do nothing" by comparing with counterfactual.

2. **MISSING: Action Magnitude Reward**

   Current: No reward for taking action
   Better: Add small bonus for |action| > threshold

   Encourages exploration and BESS utilization.

3. **MISSING: Cumulative Objective**

   Current: Step-wise rewards
   Better: Include episode-level metrics (total congestion reduction)

   Long-term consequences matter, not just immediate steps.

4. **MISSING: Inaction Penalty**

   Current: action=0 is treated same as action≠0
   Better: Explicit penalty for zero or near-zero actions

   Discourages passivity.

5. **WRONG: Penalty Dominance**

   Current: Penalties are certain, rewards uncertain
   Better: Rebalance so expected rewards > expected penalties

   Agent should be incentivized to try, not hide.

6. **WRONG: Too Conservative Entropy**

   Current: ent_coef = 0.01 (very low)
   Better: ent_coef = 0.05-0.10 for initial training

   Maintains exploration longer.

7. **WRONG: No Diversity Incentive**

   Current: All units can do same thing (all zero)
   Better: Reward using different units / distributed actions

   Prevents degenerate solutions.

```python
def calculate_improved_bess_reward(env, action, max_loading_before, max_loading_after):
    """Improved reward that prevents 'do nothing' policy collapse."""

    # 1. Congestion reward (unchanged)
    bonus_constant = env.bonus_constant
    congestion_reward = bonus_constant * (max_loading_before - max_loading_after)

    # 2. SoC penalty (unchanged)
    soc_penalty_weight = env.soc_penalty_weight
    num_near_bounds = np.sum(env.bess_soc < env.soc_min + env.soc_boundary_margin) + \
                      np.sum(env.bess_soc > env.soc_max - env.soc_boundary_margin)
    soc_penalty = soc_penalty_weight * num_near_bounds

    # 3. Flexibility bonus (modified to penalize stuck state)
    flex_weight = env.flexibility_bonus_weight
    distance = np.abs(env.bess_soc - env.soc_flex_center)
    in_band = distance <= env.soc_flex_width
    flexibility_bonus = 0.0
    if np.any(in_band):
        normalized_distance = distance[in_band] / env.soc_flex_width
        flexibility_bonus = flex_weight * np.sum(1.0 - normalized_distance)

    # NEW: Penalize stuck at center with no action
    if np.allclose(env.bess_soc, 0.5, atol=0.02) and np.all(np.abs(action) < 0.05):
        flexibility_bonus -= 20.0  # Strong penalty for being stuck

    # 4. Clipping penalty (unchanged)
    clipping_penalty_weight = env.soc_clipping_penalty
    clip_info = env.info.get('clip_info', {'units_clipped': []})
    num_clipped = len(clip_info['units_clipped'])
    clipping_penalty = clipping_penalty_weight * num_clipped

    # 5. NEW: Baseline penalty (penalize inaction)
    baseline_penalty = 0.0
    if np.all(np.abs(action) < 0.01):  # Essentially doing nothing
        baseline_penalty = -50.0  # Strong penalty

    # 6. NEW: Action utilization bonus (reward taking action)
    action_magnitude = np.mean(np.abs(action))
    action_utilization_bonus = 5.0 * action_magnitude  # 0 to +5

    # 7. NEW: Diversity bonus (reward using multiple units)
    num_active = np.sum(np.abs(action) > 0.1)
    diversity_bonus = 2.0 * num_active  # 0 to +10

    # Total reward
    total_reward = (congestion_reward +
                   soc_penalty +
                   flexibility_bonus +
                   clipping_penalty +
                   baseline_penalty +
                   action_utilization_bonus +
                   diversity_bonus)

    reward_breakdown = {
        'congestion': float(congestion_reward),
        'soc_penalty': float(soc_penalty),
        'flexibility_bonus': float(flexibility_bonus),
        'clipping_penalty': float(clipping_penalty),
        'baseline_penalty': float(baseline_penalty),  # NEW
        'action_utilization': float(action_utilization_bonus),  # NEW
        'diversity_bonus': float(diversity_bonus),  # NEW
        'num_near_bounds': int(num_near_bounds),
        'num_clipped': int(num_clipped),
    }

    return total_reward, reward_breakdown
```
