WHAT HAPPENED (Simple Explanation)
================================================================================

Your agent learned that "DOING NOTHING" gives better reward than taking actions.

Why?
- Taking action: Risks penalties (SoC violations, clipping) = average -4.5 reward
- Doing nothing: No penalties, small bonus = guaranteed +10 reward

Agent's logic: "Why risk -4.5 when I can safely get +10 by doing nothing?"

Result after 40k steps:
- All 5 BESS stopped working (power = 0)
- All SoCs stuck at 0.5 (initial value)
- Reward collapsed to -10,833
- Agent completely gave up

This is called "POLICY COLLAPSE" - a classic RL problem.

================================================================================
ROOT CAUSE ANALYSIS
================================================================================

Read the comprehensive analysis:
  ROOT_CAUSE_ANALYSIS_TRAINING_COLLAPSE.txt

Key problems identified:

1. PENALTY-DOMINATED REWARDS
   - Penalties certain (always applied for violations)
   - Rewards uncertain (depends on grid state)
   - Agent learns to minimize penalties → Do nothing!

2. NO PENALTY FOR INACTION
   - action=[0,0,0,0,0] gets +10 reward
   - No mechanism to discourage passivity
   - "Do nothing" is allowed strategy

3. ENTROPY TOO LOW
   - ent_coef: 0.01 (very low)
   - Agent stops exploring quickly
   - Once "do nothing" discovered, never tries anything else

4. NO ACTION-TAKING INCENTIVE
   - No reward for using BESS capacity
   - No bonus for exploration
   - No diversity encouragement

Mathematical proof in full analysis shows:
- Expected reward for action: -4.5
- Expected reward for nothing: +10
- Therefore: Agent CORRECTLY learned "do nothing"!

This is not a bug in PPO. This is a bug in reward design.

================================================================================
THE FIX (4 Key Changes)
================================================================================

CHANGE 1: Add Baseline Penalty
   if all actions near zero:
       penalty = -50

   Makes "do nothing" strongly negative instead of positive.

CHANGE 2: Add Action Utilization Bonus
   bonus = +5 * mean(|action|)

   Rewards using BESS capacity (up to +5 for full use).

CHANGE 3: Add Diversity Bonus
   bonus = +2 * num_active_units

   Encourages using all 5 units (up to +10).

CHANGE 4: Increase Entropy
   ent_coef: 0.01 → 0.05

   Maintains exploration longer, prevents premature convergence.

With these changes:
- "Do nothing" reward: +10 → -50 (strongly discouraged)
- "Take action" reward: -4.5 → +15 to +100 (encouraged)

Problem solved!
