ROOT CAUSE ANALYSIS
================================================================================

WHY DID TRAINING COLLAPSE?

Simple explanation:
- Agent discovered "doing nothing" gives better reward than taking actions
- Original reward: Do nothing = +10, Take action = -4.5 (average)
- Agent correctly learned to avoid risk and do nothing

Mathematical proof:
E[R_action] = P(improve) × 10 + P(violate) × (-30) = 0.30×10 + 0.50×(-30) = -12
E[R_nothing] = +10
Therefore: Agent chooses "do nothing" (rational decision!)

This is NOT a bug in PPO.
This is NOT a training error.
This is a DESIGN FLAW in the reward function.

EVIDENCE FROM YOUR TRAINING:
At step 100,350 (final):
- Active BESS units: 0 (all stopped)
- Avg power: 0 MW (no actions)
- All SoCs: 0.5 (frozen at initial)

CONCLUSION: Policy collapse confirmed from multiple sources.

================================================================================
THE SOLUTION (4 Improvements)
================================================================================

IMPROVEMENT 1: Baseline Inaction Penalty
What: Add -50 penalty when all actions near zero
Why: Makes "do nothing" costly instead of rewarding
Impact: Forces agent to take meaningful actions

IMPROVEMENT 2: Action Utilization Bonus
What: Add +5 × action_magnitude bonus
Why: Rewards using BESS capacity
Impact: Encourages active grid engagement (up to +5)

IMPROVEMENT 3: Diversity Bonus
What: Add +2 × num_active_units bonus
Why: Rewards multi-unit strategies
Impact: Prevents single-unit solutions (up to +10 for 5 units)

IMPROVEMENT 4: Increased Entropy Coefficient
What: Change ent_coef from 0.01 to 0.05
Why: Maintains exploration longer
Impact: Prevents premature convergence

COMBINED EFFECT:
"Do nothing" reward: +10 → -50 (discouraged)
"Take action" reward: -4.5 → +15 to +100 (encouraged)

New expected rewards:
E[R_action] = base + utilization + diversity - penalties = +15.55
E[R_nothing] = -50 (inaction penalty)
Therefore: Agent will choose "take action" (problem solved!)
