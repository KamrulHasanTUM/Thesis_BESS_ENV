BEFORE YOU TRAIN - UNDERSTAND THE CHANGES
================================================================================

WHAT THESE CHANGES DO:

CHANGE 1 (bonus_constant 60→100):
├─ Strengthens congestion reduction reward
├─ Previously: Activity bonuses (~25) were 42% of congestion reward (60)
├─ Now: Activity bonuses (~25) are 25% of congestion reward (100)
├─ Effect: Agent prioritizes congestion more, but activity still matters
└─ Prevents: Reward imbalance that caused 6k breakdown

CHANGE 2 (timesteps 10k→50k):
├─ 5× more training time
├─ Previously: Agent converged at 6k (before learning enough)
├─ Now: Agent has 50k steps to explore before committing to strategy
├─ Effect: More time to find optimal policy
└─ Prevents: Premature convergence to local minimum

CHANGE 3 (learning_rate 0.0003→0.0001):
├─ 3× slower learning
├─ Previously: Aggressive updates → rapid but unstable convergence
├─ Now: Gradual updates → stable, reliable convergence
├─ Effect: Smoother learning curve, less volatility
└─ Prevents: Overshooting optimal policy

CHANGE 4 (soc_drift_penalty redesign):
├─ Allows 40-60% SoC range without penalty
├─ Previously: ANY drift from 50% penalized
├─ Now: Only severe drift (<40% or >60%) penalized
├─ Effect: Agent can discharge heavily when needed for congestion
└─ Prevents: Conflict between "reduce congestion" and "maintain SoC"

CHANGE 5 (monitoring additions):
├─ Adds mean_soc and drift amount to WandB logs
├─ Previously: Only saw penalty value
├─ Now: Can track exact SoC levels and when penalty activates
├─ Effect: Better visibility into agent behavior
└─ Helps: Debug and tune if issues arise
